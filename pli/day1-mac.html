SELF-STUDY · 2026-09-12

Mac 첫 샘플 실습

먼저 Mac 준비 안내를 완료하세요. 이번 단계는 제공 재료로 로컬 영상 한 편을 만드는 데 집중합니다.

1. 올바른 폴더 열기

Orca 또는 설치한 AI 작업 앱에서 홈 폴더의 플리공장를 엽니다. 폴더 안에 시작하세요.md, 공장.py, 재료가 보이는지 확인합니다.

2. 읽기 전용 검사

시작하세요.md와 샘플재료_이용안내.md를 읽고 준비 상태를 확인해줘.
Python·ffmpeg·ffprobe와 공장.py, 점검.py, 설정.json, 재료 폴더의 샘플 4종을 확인해줘.
유튜브 API 키 값은 읽거나 출력하지 말고, 새 프로그램을 설치하거나 파일을 바꾸기 전에는 설명해줘.

샘플은 음원·가사·배경·썸네일 네 종류입니다. 분석 API 키가 빈 것은 기본 실습의 오류가 아닙니다.

3. 샘플 제작

샘플 재료를 공장.py 검사로 확인해줘. 통과하면 공장.py로 연습 영상과 제목·설명 파일을 만들어줘.
유튜브에는 올리지 말고 새 노래나 이미지를 생성하지 마.
완성 파일의 실제 경로와 영상 길이·해상도·오디오 유무를 보여주고 폴더를 열어줘.

4. 직접 재생

  1. ‘완성’ 폴더에서 MP4를 두 번 눌러 재생합니다.
  2. 처음·중간·끝의 소리와 배경을 확인합니다.
  3. 같은 번호의 제목·설명 txt를 열어 내용이 있는지 확인합니다.
기본 실습 완료

MP4와 제목·설명 파일이 만들어지고 직접 재생했습니다. 이 결과만으로 기본 제작 실습 완료입니다. 샘플을 공개하거나 예약할 필요는 없습니다.

다음 단계

2장 내 채널 방향과 첫 곡으로 이어갑니다. 유료 생성이 어렵다면 샘플로 제작·검수 흐름을 먼저 익히고 응용은 나중에 진행해도 됩니다. 업로드를 원할 때는 7장 비공개 업로드를 따릅니다.
