샘플로 시작해, 내 영상으로 이어가기

이 교재는 플리공장 자동화 프로젝트의 자습판입니다. 정해진 시작일·다운로드 마감·곡 수 의무가 없습니다.

혼자 진행하되, 막히면 함께 해결해요.

구매하신 분은 그밤PD 카카오톡 1:1 오픈채팅을 열어 드립니다. 링크는 결제 뒤 문자로 보내 드립니다. 교재를 자신의 속도로 따라가고, 궁금하거나 어려운 부분은 질문을 남겨주세요. 함께 확인하고 해결해 나갑니다. 매일 제출하거나 운영자 승인을 기다릴 필요는 없습니다.

초대 방법은 구매 완료 메시지를 확인하세요. 안내를 찾지 못했다면 메시지의 판매자 문의 경로로 구매 내역을 알려주세요.

  • AI 구독과 음악·이미지 생성 서비스 비용은 상품 구매에 포함되지 않습니다. 계정에 표시된 현재 기능·사용량·비용을 확인하세요.
  • 첫 샘플 영상은 제공 음원과 이미지를 쓰므로 Suno 생성이나 채널 분석 API 키가 필요 없습니다.

Windows 준비 · Mac 준비 · 1장 시작

1장

설치하고 첫 샘플 영상 만들기

구매 완료 메시지에서 플리공장_셋팅코드.zip을 내려받습니다. ZIP은 임의로 다시 압축하거나 이름을 바꾸지 않습니다.

  1. 운영체제에 맞게 준비

    Windows 또는 Mac 준비 페이지를 따릅니다.

  2. 공장 폴더 열기

    Windows 설치·실습 또는 Mac 설치·실습에서 폴더를 연결합니다.

  3. 제공 샘플 검사 후 제작

    아래 문장을 공장 폴더를 연 AI 입력칸에 붙여넣습니다.

시작하세요.md와 샘플재료_이용안내.md를 읽어줘.
제공된 샘플 4종이 있는지 확인하고 공장.py 검사부터 실행해줘.
검사가 통과하면 샘플로 영상과 제목·설명 파일을 만들어줘. 새 노래 생성이나 유튜브 업로드는 하지 마.
완성 파일의 실제 경로와 영상 길이를 보여주고 폴더를 열어줘.
성공 기준

‘완성’ 폴더에 MP4와 제목·설명 txt가 있고, MP4를 직접 열어 배경과 소리를 확인했습니다. 샘플의 길이는 약 2분입니다.

첫 영상이 만들어지면 기본 제작 실습 완료입니다. 샘플은 로컬 제작과 비공개 업로드 연습 전용이며 공개·예약·수익화에 사용하지 않습니다.

오류가 나면 질문·복구 안내를 보고, 원본 자료를 삭제하지 마세요.

2장

내 채널 방향과 첫 곡 정하기

처음부터 많은 곡을 만들지 않습니다. 상황·분위기·보컬을 정하고 A/B 한 쌍으로 생성과 다운로드를 익힙니다.

설정.json의 채널명·컨셉을 바꾸고 싶어. 내가 어떤 상황에서 듣는 음악을 만들고 싶은지 한 질문씩 물어봐줘.
내 답으로 채널명 후보 3개와 컨셉 한 줄을 제안하고, 내가 고른 값만 저장해줘. API 키는 필요 없어.

첫 곡 주문

작사스킬.md와 곡형식_8가지.md를 읽어줘.
내 채널에 맞는 곡 하나의 가사·Styles·Exclude·제목을 준비해줘. 특정 가수나 기존 곡을 모사하지 마.
Suno에서 생성하기 전에 현재 모델·예상 사용량과 계정의 크레딧을 확인하고 내 승인을 기다려줘.
처음에는 A/B 한 쌍만 생성하고 둘 다 다운로드해줘. 내가 듣고 한 곡을 고를 때까지 다음 곡은 만들지 마. 로그인·결제·인증은 내가 직접 할게.

자동 브라우저 조작을 사용할 수 없다면 AI가 만든 제목·가사·스타일을 Suno의 해당 입력칸에 직접 붙여넣습니다. 화면 이름이 교재와 다르면 현재 입력칸을 확인한 후 진행하세요. 생성 기능이나 다운로드가 제한되면 결제부터 하지 말고 멈춰서 질문합니다.

성공 기준

내 채널명·컨셉이 저장되고, A/B를 직접 들어 선택을 기록했습니다. 생성 불가 시 채널 방향과 가사 초안까지만 저장하고 제공 샘플로 제작 연습을 이어갈 수 있습니다.

3장

파일·기록·백업 갖추기

화면에 곡이 보이는 것과 내 컴퓨터에 파일이 저장된 것은 다릅니다. 날짜 마감이나 500개 목표 없이 실제 다운로드 한 쌍부터 확인하세요.

  1. Suno 라이브러리에서 해당 곡의 더보기 → 다운로드를 열고 이용 가능한 오디오 형식으로 저장합니다.
  2. 다운로드 폴더에서 A와 B 파일을 각각 재생합니다.
  3. AI에게 파일 위치를 알려 아래 정리를 요청합니다. 원본은 삭제하지 않습니다.
이번에 받은 A/B 파일의 실제 경로·개수·길이·재생 가능 여부를 확인해줘.
곡창고에 원본을 보관하고 기록/곡목록.csv에 제목, A/B, 파일명, 곡 주소 또는 ID, 생성일, 생성 당시 플랜, 선택 여부를 적어줘. 모르는 정보는 확인 필요로 남겨줘.
기록/권리확인.md에는 본인 생성 확인, 생성일, 당시 플랜, 게시 목적, 입력 재료 권리와 출처 표기 확인을 곡별로 정리해줘. 증빙은 지어내지 마.
백업할 폴더는 먼저 나에게 물어보고, 복사 뒤 원본과 개수·크기를 대조해줘.

컴퓨터가 꺼지면 먼저 완료 파일과 기록을 대조하고 마지막 성공 다음부터 이어갑니다. Mac은 전원 연결 후 제작하는 동안 터미널의 caffeinate -i를 켜 둘 수 있으며 끝나면 Ctrl+C로 종료합니다. Windows는 설정의 전원·절전에서 전원 연결 중 절전 시간을 확인하고, 제작이 끝나면 원래 설정으로 되돌립니다.

성공 기준

다운로드한 파일이 열리고, 파일 수·곡목록·백업 파일 수가 일치합니다. 공개할 권리가 불명확한 재료는 공개 단계로 넘기지 않습니다.

4장

쓸 곡을 고르고 순서 정하기

AI의 기술 검사와 사람의 청취는 역할이 다릅니다. AI는 파일 오류를 찾고, 어떤 곡을 쓸지는 직접 선택합니다.

곡창고의 A/B를 한 쌍씩 보여줘. 내가 직접 듣고 A 또는 B를 선택할 때까지 기다려줘.
선택한 곡만 파일 열림·길이·긴 무음·끝 잘림 의심·완전 중복을 검사해줘. 문제가 의심되면 해당 구간을 듣게 해줘.
이번 영상에 쓸 곡 순서를 제안하고 내 확인을 받아줘. 미선택 곡과 샘플은 삭제하지 말고 보관 위치를 먼저 알려줘.
  1. A와 B의 시작·중간·끝을 듣고 하나를 고릅니다.
  2. 클릭음·갑자기 잘린 끝·반복이 심한 부분을 확인합니다.
  3. 먼저 한 곡으로 제작을 완료해도 됩니다. 여러 곡 구성은 원하는 수량과 사용량을 정한 뒤 반복합니다.
  4. 이번 영상에 쓸 곡만 ‘재료’ 폴더에 복사하고 파일명 앞에 01, 02처럼 순서를 붙입니다. 샘플이 섞이지 않았는지 확인합니다.
성공 기준

사용할 곡과 순서가 정해졌고, 재료 폴더에 미선택 곡이나 샘플이 섞여 있지 않습니다. 선택은 곡목록에 기록됐습니다.

5장

정적 배경으로 영상 만들기

기본 공장은 음악과 배경 이미지를 합치는 방식입니다. 음악에 반응하는 파형은 이 배포본에 포함된 필수 기능이 아닙니다. 설정을 켜거나 코드를 개조할 필요가 없습니다.

이미지 준비

직접 만들었거나 이용 권한을 확인한 이미지로 배경 1920×1080, 썸네일 1280×720을 준비합니다. 이미지 생성 기능이 없으면 본인 이미지로 실습하세요. 샘플 이미지는 샘플 연습에서만 사용합니다.

이번 영상의 곡 순서와 재료 폴더를 확인해줘. 배경 한 장·썸네일 한 장을 보여주고 내가 선택한 파일을 써줘.
공장.py 검사 후 문제가 없으면 기본 정적 배경으로 MP4와 제목·설명 파일을 만들어줘. 음파 효과나 새 코드를 추가하지 마.
업로드하지 말고 출력 파일의 길이·해상도·오디오 유무와 실제 경로를 보여줘.

완성 MP4를 열어 시작·중간·곡 경계·끝을 확인합니다. 영상 길이는 곡 수로 추측하지 말고 실제 파일을 확인합니다. 무음 정리와 곡 사이 연결 처리로 원본 길이 단순 합계와 다를 수 있습니다.

성공 기준

MP4와 제목·설명 txt가 열리고 곡 순서·배경·소리가 맞습니다. 업로드 없이 여기서 중간 저장하고 쉬어도 됩니다.

6장

썸네일·제목·설명 검수하기

썸네일 참고 보드에서는 색·중심 대상·글자 크기만 관찰합니다. 다른 채널의 이미지나 문구를 그대로 복사하지 않습니다.

완성한 영상의 제목 후보와 설명을 보여줘. 채널명 예시값이 남아 있는지, 곡 순서·시간표·출처가 실제 재료와 맞는지 확인해줘.
썸네일을 작게 보여줘. 중요한 대상과 짧은 문구가 읽히는지 비교하고 내가 고른 한 장을 사용해줘.
아직 업로드하거나 예약하지 말고 검수 결과와 남은 항목만 알려줘.
  • 채널명과 제목의 예시 문구를 내 값으로 바꿉니다.
  • 설명문의 곡 목록·시간표를 실제 영상과 비교합니다.
  • 썸네일을 휴대폰 크기에서 확인합니다.
  • 공개 여부를 결정하기 전에 음원·이미지 이용 조건과 필요한 출처 표시를 확인합니다.
성공 기준

제목 한 개·설명·썸네일 한 장을 직접 확인했고, 남은 권리 확인 항목을 알고 있습니다. 확인이 끝나지 않은 재료는 비공개 연습까지만 진행합니다.

7장

비공개 업로드 확인, 예약은 선택

로컬 영상 제작과 업로드는 별도 단계입니다. 첫 업로드는 선택한 영상 한 편을 비공개로 저장합니다.

유튜브 로그인 창을 열어줘. 로그인·비밀번호·인증번호는 내가 직접 입력할게.
로그인한 채널과 올릴 영상 번호·제목·썸네일을 먼저 보여줘. 내가 확인하면 그 영상 하나만 비공개로 업로드해줘. 예약하거나 공개하지 마.
이미 같은 영상이 올라갔는지 확인하고, 실패하면 중복 업로드 전에 Studio의 현재 상태부터 확인해줘.

업로더가 실행되는 동안 브라우저를 다른 용도로 조작하지 않습니다. 끝났다는 답만 보지 말고 YouTube Studio → 콘텐츠에서 선택한 영상과 비공개 상태를 직접 확인합니다.

자동 업로드가 막히면 — 수동 경로

  1. YouTube Studio를 엽니다. 먼저 같은 영상이 이미 저장됐는지 확인합니다.
  2. 새로 올려야 한다면 만들기 → 동영상 업로드에서 완성 MP4를 선택합니다.
  3. 검수한 제목·설명을 붙이고 썸네일을 선택합니다.
  4. 시청자층과 AI 사용 등 질문에 실제 내용대로 답하고 검사 결과를 확인합니다.
  5. 공개 상태를 비공개로 저장하고 콘텐츠 목록에서 재확인합니다.

본인 영상 예약하기 — 선택

샘플은 예약하지 않습니다. 본인 재료의 권리를 확인하고 영상 검수를 마친 경우에만 앞으로의 날짜·시각·시간대를 직접 정합니다. 자동 업로더는 기존 확인 장치를 유지합니다.

권리 확인과 검수가 끝난 내 영상 하나만 예약하고 싶어.
영상 번호·채널·제목·썸네일·희망 날짜와 시간대를 먼저 확인해줘. 내가 날짜·시각을 정하고 최종 확인하기 전에는 예약하지 마.
완료 후 Studio에 실제 표시된 공개 상태와 예약 시각을 확인하게 안내해줘.
