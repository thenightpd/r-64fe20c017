2. 준비물 확인

  • Windows 컴퓨터와 인터넷, 설치할 수 있는 사용자 권한이 필요합니다.
  • AI 작업 환경의 계정과 구독·사용량은 본인이 준비합니다. 모든 외부 서비스 비용이 상품에 포함된 것은 아닙니다.
  • 회사·학교 컴퓨터가 설치를 제한하면 정책을 우회하지 말고 관리자에게 문의합니다.

3. 셋팅코드 ZIP 꺼내 두기

  1. 구매 후 받은 플리 채널 자동화_전체패키지.zip을 다운로드 폴더에서 마우스 오른쪽 → 압축 풀기(Windows 10은 모두 압축 풀기)로 풉니다.
  2. 풀린 폴더의 03_실습파일 안에 플리공장_셋팅코드.zip이 있습니다. 이 ZIP은 풀지 않습니다. 설치 도우미가 직접 검사하고 풉니다.
  3. 설치 도우미는 다운로드 폴더와 바탕화면을 하위 폴더까지 찾아봅니다. 전체패키지를 다운로드 폴더에 풀었다면 그대로 두면 됩니다. USB나 다른 드라이브에 풀었다면 플리공장_셋팅코드.zip만 다운로드 폴더로 복사하세요.
  4. 이름 뒤에 (1)이 붙어도 괜찮습니다. 설치 도우미가 내용을 검사해 공식 파일만 씁니다.

4. 설치 도우미 실행

② 아래 복사를 누르고, PowerShell 창 안을 한 번 누른 뒤 Ctrl+V로 붙여넣고 Enter를 누릅니다. “여러 줄을 붙여넣으려고 합니다” 같은 확인 창이 뜨면 붙여넣기를 누릅니다.

시작 메뉴에서 PowerShell을 검색해 엽니다. 아래는 Claude를 선택한 예시입니다. Codex를 사용한다면 첫 줄의 claude만 codex로 바꿉니다. 이미 사용하는 계정 하나를 선택하면 됩니다.

설치 도우미는 Git·Python·ffmpeg·Node.js·Chrome·선택한 AI 도구·Orca와 필요한 패키지를 준비합니다. 실제 설치 내용을 확인하고 진행하세요. 다운로드·설치 중 15~30분 이상 걸릴 수 있습니다. 암호·로그인·동의 화면은 직접 처리하고 채팅에 보내지 않습니다.
[Net.ServicePointManager]::SecurityProtocol = 'Tls12'
$env:PLI_AI = 'claude'
$setupFile = Join-Path $env:TEMP 'pli-setup.ps1'
Invoke-WebRequest 'https://raw.githubusercontent.com/thenightpd/r-64fe20c017/main/pli/setup.ps1' -OutFile $setupFile
powershell -NoProfile -ExecutionPolicy Bypass -File $setupFile

Windows에서 설치 동의나 사용자 계정 확인 창이 뜨면 게시자와 설치 항목을 읽고 진행합니다. 실행 정책은 위 명령의 해당 프로세스에만 적용되며 전역 설정을 변경하지 않습니다.

끝나면 결과 표를 읽습니다. ‘나중에’는 지금 없어도 되는 항목(채널 분석 API 키·수노 브라우저 연결)이라 그대로 두어도 됩니다. 확인 필요·재실행 필요가 있으면 오류 문구를 남기고, 터미널과 AI 앱을 다시 열어 설치 상태를 재확인합니다. 반복 실행 전에 이미 설치된 항목과 실패한 항목을 구분하세요.

5. 공장 폴더와 계정 확인

Orca를 열고 선택한 AI 계정에 로그인합니다. 프로젝트/폴더 열기에서 C:\플리공장 폴더만 선택합니다. 홈 전체·바탕화면 전체를 연결하지 않습니다. 로그인 항목은 계정 화면의 현재 안내를 따르고 비밀번호·인증 코드는 직접 입력합니다.

처음 여는 분은 여기까지 따라오세요

  1. 설치 마지막에 열린 로그인 안내를 확인합니다. 브라우저가 열리면 사용할 계정으로 직접 로그인하고, 완료 후 터미널로 돌아옵니다. 결제한 계정과 로그인 계정이 같은지 확인하세요.
  2. 로그인 창이 열리지 않았다면 터미널에 선택한 도구 이름인 claude 또는 codex를 입력해 현재 안내를 따릅니다.
  3. Orca를 열고 Add Project → 폴더 찾아보기를 선택합니다. 폴더 선택 창의 주소칸에 C:\플리공장을 입력한 뒤 Enter → 폴더 선택을 누릅니다.
  4. 가운데 터미널/입력 영역을 누르고 선택한 도구 이름 claude 또는 codex를 입력한 뒤 Enter를 누릅니다. 파일 목록 칸에 입력하지 않습니다.
  5. 폴더 신뢰 여부를 물으면 경로가 방금 설치한 플리공장인지 확인한 뒤 결정합니다. 로그인·동의·권한 요청은 내용을 읽고 진행합니다. 알 수 없는 질문은 캡처해 그밤PD 카톡 1:1 오픈채팅에 물어보세요.
  6. AI 인사말과 입력줄이 보이면 아래 상태 확인 문장을 붙여넣습니다. 붙여넣기는 Ctrl+V입니다.

Orca가 손상됐다는 경고가 나오면 실행을 반복하거나 보안 설정을 우회하지 않습니다. 공식 설치 안내를 확인하고 오류 화면과 운영체제를 그밤PD 카톡 1:1 오픈채팅에 남겨주세요.

준비 완료 기준

선택한 AI에 로그인했고 공장 폴더에서 대화할 수 있습니다. 공장.py·점검.py·설정.json·재료 4종이 있고 Python·ffmpeg가 준비됐습니다. API 키·YouTube 로그인·Suno 계정은 이 완료 기준에 포함되지 않습니다.
